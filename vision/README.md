# 视觉端

## peer/  —— 仿真桥接 + 自瞄主循环

- `plugyou_peer.py`：UDP 收发、检测→PnP→角度、指令下发、调试打印、偏置热调
- `wl_lightbar.py`：灯条检测 + 官方配对 + 角点精修
- `yaw_pnp.py`：PnP 方位解算的独立验证脚本

## stack/ —— 视觉栈（PlugYourRM 子集）

- `custom/components/armor_solvers/`：PnP 求解器（ippe / qcqp / diff）
- `core/`：总线、实体、算法（EKF 等）
- `entrance/`：主程序入口
- `sim/`：仿真渲染/管理（可选）

## 关键结论（实测）

1. **PnP 方位很准**：与仿真真值差 0.13 ~ 0.60°
2. **相机外参平移必须用"相机→炮口"**，不能用"相机→云台转轴"，否则近距偏 ~9° 且随目标左右翻符号
3. **装甲板并非全部垂直**：正面 0.00°，侧面 −15.87°（实测）
4. **小陀螺乱跳** = 两块板轮流经过画面中心 ⇒ 已用"时间关联+迟滞"修掉
5. 求解器的 `mount_pitch` 参数不参与解算（只被抄进返回的欧拉角）
