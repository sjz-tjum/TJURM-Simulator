# TJURM-Simulator

RoboMaster 仿真自瞄 / 操作端 / 裁判系统 代码归档。

> 本仓库是 **UE4.27 仿真工程（RM2019Sim）之外的配套代码**：视觉端（Python）、
> 操作端调试工具、以及从 UE 工程抽出的裁判系统 C++ 源码。
> UE 工程本体（美术资源/关卡/蓝图）不在此仓库内。

## 目录结构

```
vision/
  peer/    视觉端 ↔ 仿真的 UDP 桥接 + 自瞄主循环（plugyou_peer.py）
  stack/   视觉栈（PlugYourRM 子集）：检测 / 灯条精修 / PnP / EKF
operator/
  tools/   操作端调试工具：偏置热调窗口、摆车/校验/灯光等脚本
  hud/     UE 屏幕调试显示（绿框/概率/PnP 真值对照）
referee/   裁判系统（UE C++）：血量/热量/电容、PVP 对局、Arena
docs/      链路与协议文档
```

## 三条链路

### 1. 视觉端（自瞄）

```
板系 3D 点(左上/右上/左下/右下) + 图像 2D 角点 + 内参 K
        │  PnP (IPPE / 单应)
        ▼
   相机系 t_c1
        │  相机外参 M = R_chassisᵀ · R_camera
        │      xyz = 相机→**炮口**的安装偏移（实测/仿真帧包 Dx,Dy,Dz）
        │      rpy = 运行时云台转角（相对固定云台系）
        ▼
  固定云台系 pos = M · t_c1 + t_cam
        │
        ▼
  云台系下的目标角（相对炮口）→ UDP 41003 → 仿真
```

**核心约定**（踩过的坑，别改错）：

| 项 | 约定 |
|---|---|
| 目标角 | 发 **云台系下的相对角**（正=左），仿真直接把它清零即可，**不要**绕世界系 |
| 相机外参平移 | 必须是 **相机→炮口**（`BestT-MuzzleWb`），**不是**相机→云台转轴（差一段枪管 ≈0.25 m，近距会偏 ~9° 且随目标左右翻符号） |
| 装甲板倾角 | 不同面的板倾角不同（实测：正面 **0.00°**，侧面 **−15.87°**）；当前求解器的 `mount_pitch` 参数**不参与解算**，倾角靠板身份/几何处理 |
| 灯条配对 | 按官方 `getBestMatchedLightbarPair` 全组合 + 几何约束；角点顺序 **左上/右上/左下/右下** |
| 选板 | **时间关联 + 迟滞**（优先跟上一帧那块板），否则小陀螺时两块板轮流中选 ⇒ 角度乱跳 |
| 视觉伺服 | 像素误差 PI/速率环（老路径），保留用于对照；它与 PnP 相差的是"相机基准 vs 炮口基准"的视差，不是错误 |

### 2. 操作端

- `bias_window.bat`：一键起 peer（可见控制台，支持键盘热调偏置）
- `WLBoostHUD`：屏幕显示检测绿框、概率、PnP 与真值对照
- 其余：摆车、关卡生成、灯条材质、真值标定脚本

### 3. 裁判系统（referee/）

从 UE 工程抽出的裁判/对局相关源码：

| 文件 | 内容 |
|---|---|
| `WLRefereeSystem.*` | 血量 / 热量 / 电容 / 弹量 的存储与恢复、击打结算 |
| `WLPVPArena.*` | PVP 对局：出生点、复活、胜负判定、场地规则 |
| `WLAimNet.*` | 视觉链路（UDP 41001–41004）编码/解码 |

## UDP 协议（41001–41004）

| 端口 | 方向 | 内容 |
|---|---|---|
| 41001 | 仿真 → 视觉 | 帧（`RMAI`，chunk0 带 JPEG + 36B 相机位姿 `FCamPose`） |
| 41002 | 仿真 → 视觉 | 状态（`RMST`，offset20 = RangeCm，offset24 = 18 floats 位姿） |
| 41003 | 视觉 → 仿真 | 指令（`RMCM`，code 1 = 绝对/相对角通道） |
| 41004 | 视觉 → 仿真 | 检测回传（绿框） |

`FCamPose`：`Px,Py,Pz`（相机世界位置 m）/ `Yaw,Pitch,Roll`（度）/ `Dx,Dy,Dz`（**相机→炮口** m）
